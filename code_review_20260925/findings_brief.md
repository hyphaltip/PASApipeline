# Findings brief (Opus 5.5 review, 2026-09-25) — for debate agents

Pipeline: funannotate train -> Trinity + long reads -> minimap2 (-ax splice --cs -u b, --junc-bed) -> funannotate library.py bam2gff3 -> PASA (--ALIGNERS blat,gmap + --IMPORT_CUSTOM_ALIGNMENTS minimap2 GFF3, --stringent_alignment_overlap 30, --TRANSDECODER, --ALT_SPLICE) -> pasa_asmbls_to_training_set.dbi (TransDecoder LongOrfs/Predict, no --single_best_only, start refinement on) -> train.py getBestModel (kallisto TPM first key) -> predict.py selectTrainingModels -> Augustus (etraining/optimize) + SNAP (fathom uni) -> EVM (PASA weight default 6).

Observed: overabundant single-exon models, poor mapping, poor training sets.

## Confirmed findings (code read + data or executed test)
1. Fork master bug (bce776a, 2026-06-29): PASA_transcripts_and_assemblies_to_GFF3.dbi printed every GFF3/GTF row twice. cdna_alignment_orf_to_genome_orf.pl does not dedupe exons, so CDS mapping to genome is wrong (truncated, off-frame). Benchmark: 47,990 of 95,980 rows duplicated. A. fumigatus: v1.8.17 single-CDS training models 35.9%, mean CDS 1,118 nt; v1.9.0-beta.5 (doubled rows) 53.3%, 805 nt. Also all minus-strand ORFs on unspliced assemblies dropped (4,850). Fixed on HEAD 4376a22 (2026-09-21).
2. funannotate bam2gff3 (library.py ~1873-1914, logic from 2018): cs '*' substitution and '-' deletion do not advance genome position -> exon boundaries after the first mismatch shift; soft clips counted as aligned (Target 1..len(SEQ)) -> MIN_PERCENT_ALIGNED ineffective; intron motif judged vs SAM flag not transcript strand -> flag-0 alignments of minus-strand genes and GC-AG introns rejected; only last intron decides. Net: spliced custom alignments lost or invalidated by PASA's strict splice-boundary check; unspliced ones pass.
3. --stringent_alignment_overlap partitions clusters by scaffold;spliced_orient. Single-exon alignments have orient '?', never cluster with overlapping spliced alignments -> separate single-exon assemblies/genes.
4. Launch_PASA_pipeline.pl:821 ensure_single_valid_alignment_per_cdna_per_cluster only runs if -N>1 or zero aligners (upstream too; likely inverted). blat+gmap+custom alignments of same transcript all assembled.
5. Rust assembler (pasa_rust) selects assemblies differently from C++ (keeps extra partly redundant assemblies on ~2% of random inputs; nondeterministic ordering). Fork master preferred pasa_rust; HEAD prefers C++ pasa. C++ HEAD output byte-identical to upstream on 419 test inputs.
6. Training selection: no completeness/in-frame-stop/min-length filter when keeperCheck falls back; single-exon genes only excluded if >=200 multi-exon models exist (all-or-nothing). filterGenemark.pl misreads minus-strand genes in dict2gtf order (strand bias, all complete single-exon genes pass). getBestModel ranks by TPM first, overlap is asymmetric and strand-blind -> overlapping models retained (433 same-strand overlaps in v1.8.17 set). selectTrainingModels overlap removal non-transitive.
7. TransDecoder: multiple ORFs per assembly retained (5,548/11,904 assemblies >1 ORF), start refinement relabels 5'partial as complete after moving start up to 15% downstream.
8. Augustus: etraining run on full TrainSet before random split -> test accuracy inflated (leakage).
9. Minor: shard_subcluster_builder.sh can write empty output + .ok if run too early; find_alternate_internal_exons swallows DB errors; fasta36 -p semantics unverified; OpenMP oversubscription in pasa.

## Recommendations drafted so far
R0 rerun with HEAD; add duplicate-row guard. R1 complete ORFs only, drop refined-start models or run --no_refine_starts. R2 min CDS length (e.g. 300 aa — threshold unjustified by data). R3 all introns supported by RNA-seq junctions (Python, replace filterGenemark). R4 cap single-exon fraction to genome-realistic proportion instead of all-or-nothing. R5 strand-aware symmetric locus clustering, one model per locus. R6 protein redundancy <=70-80% identity. R7 homology/BUSCO support with start/stop agreement. R8 --single_best_only option. R9 fix etraining leakage. Plus fix bam2gff3 via CIGAR, fix Launch:821 condition, cluster '?' alignments with overlapping spliced partitions.
